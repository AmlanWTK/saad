# saad

Career intake form for Sadibne Munsur — international development CV.

**Open the form:** https://amlanwtk.github.io/saad/ (works once GitHub Pages is enabled — see below)

## For Sadibne

1. Open the link in Chrome on your phone or laptop.
2. Answer the questions in English or Bangla. Answers save automatically in that browser, so you can return over several days — just use the same browser and device.
3. When finished, press **Export answers** and send the downloaded file back. **Copy all** puts everything on the clipboard (for WhatsApp/email) if download does not work.

## Enabling GitHub Pages (one-time, repo owner)

Repository → Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save. The page is live at the link above within a minute or two.
